# Attribution and publication scope

The proposed core, affine parameters, 25 benchmark LUTs, and gate netlists are
transcribed from the manuscript supplied by the user. The circuit PDF/PNG assets
are derived from its supplied diagrams. The included bibliography records the
manuscript's sources; it is not a new citation audit.

The application and tests were created for this project. No repository-wide
open-source license has been chosen on behalf of the manuscript authors. Before
public release, the owner should select a license and confirm permission for the
manuscript-derived assets. Third-party Python packages retain their own licenses.

This project has not been uploaded to GitHub automatically. No author affiliation,
funding declaration, DOI, or publication acceptance is asserted by the software.
